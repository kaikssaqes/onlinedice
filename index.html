How do these virtual dice work?

This website uses virtual dice created with an algorithm that assigns equal probabilities to every possible outcome. By clicking on the 'Go Again' button you can re-roll all the dice on this page.

This page allows you to choose any number of dice between 1 and 100, each having 6 sides and 6 possible colors:
Red, Orange, Yellow, Green, Blue and Purple.

About us

Online-Dice.com is an online dice simulator that anyone can use to roll virtual dice when no real dice are available. With this free simulator you can roll dice for online games, board games, or any other game of chance.
